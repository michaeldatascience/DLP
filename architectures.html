The single most useful sentence about decoder-only models A decoder-only model is not "half a transformer". It is the decoder with the cross-attention layer removed, because cross-attention exists only to read an encoder's output and there is no encoder to read. That is why GPT's block has two sublayers — masked attention and feed-forward — while the full decoder has three. Select Decoder-only above and the cross-attention block is the one that greys out inside an otherwise intact column.
02

What actually changes: the mask

The families share their machinery almost exactly. What really separates them is which cells of the attention matrix are allowed. A cell holds 0 where attention is permitted and −∞ where it is blocked, because −∞ becomes 0 after softmax and so contributes nothing.

Rows are queries — the token doing the looking. Columns are keys — the token being looked at. Cell (i,j) asks: may token i attend to token j?

The off-by-one that 2026 T2 made a 3-mark question 
causal_mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=0).bool()
masked_scores = scores.masked_fill(causal_mask, float("-inf"))
attn_weights  = F.softmax(masked_scores, dim=-1)

diagonal=0 includes the main diagonal, so every token is forbidden from attending to itself. Row 0 then has nothing left to look at — it is entirely −∞ — and softmax over a row of all −∞ gives NaN. Set the selector above to 0 and watch the first row turn solid red. The fix is diagonal=1, which blocks only what is strictly above the diagonal.

Why the course calls the mask "strictly upper triangular" The blocked cells — the −∞ entries — sit strictly above the main diagonal. The deck writes it out as a 4×4 matrix with zeros on and below the diagonal and −∞ above. A past paper marked "the attention mask is strictly upper triangular" as a correct statement, so the wording matters.

2026 T2 · Q9 · 3 marks

The following code is intended to implement causal masking for self-attention, where each token can attend only to itself and previous tokens. seq_len = 4, causal_mask = torch.triu(torch.ones(seq_len, seq_len), diagonal=0).bool(), then masked_fill(causal_mask, float("-inf")) and a softmax over the last dimension. What is the effect of running this code as written?

1
torch.triu(M, diagonal=k) keeps the upper triangle starting k positions from the main diagonal. At k=0 the main diagonal is included.
2
Those kept entries are what gets filled with −∞. So cell (i,i) — a token attending to itself — is blocked, which is not what causal masking means. Causal allows self-attention; it blocks only the future.
3
Row 0 has no past at all, and now loses itself too, so every cell in row 0 is −∞.
4
Softmax over a row of all −∞ divides zero by zero and produces NaN. Switch the panel above to diagonal=0 to see the row turn solid red.
5
Reject the two tempting distractors: it raises no RuntimeError — triu and masked_fill compose perfectly legally — and the weights do not "sum to more than 1", because softmax always normalises to 1 wherever it is defined at all.
The current token is masked too; row 0 becomes entirely −∞, which can yield NaN weights
2026 T1 · Q14 · 3 marks · multiple select

Which statements correctly distinguish different Transformer architectures and their typical training objectives? (a) Encoder-only models are commonly trained with Masked Language Modelling objectives. (b) Decoder-only models rely on causal masking and autoregressive inference. (c) Encoder-decoder models are well suited for sequence-to-sequence tasks. (d) All Transformer architectures use identical attention masks.

1
(a), (b) and (c) are each the textbook pairing of a family with its objective. All three correct.
2
(d) is the odd one out, and it is false for the exact reason this page exists: the mask is the one thing that genuinely differs. An encoder has none; a decoder has a strictly upper triangular one.
3
Pattern worth noting: in a four-option multiple-select on this paper, three options were correct and the fourth contained the word "identical". Absolutes stay a reliable tell.
(a), (b), (c) — not (d)
2026 T1 · Q16 · 3 marks · multiple select

A model is trained using the Causal Language Modelling objective with a standard cross-entropy loss. Which statements correctly describe the training dynamics? (a) The loss at position t depends only on tokens before t. (b) The attention mask is strictly upper triangular. (c) Future tokens contribute gradients to earlier positions. (d) The joint probability of the sequence is factorised autoregressively.

1
(a) True. That is the definition of causal: the prediction at t is conditioned on x₁…x₍t₋₁₎ and nothing later.
2
(b) True, in the deck's own words — the −∞ entries lie strictly above the diagonal.
3
(c) False, and this is the one that catches people. Gradients flow backwards through the computation graph, but the mask severed the forward connection from future tokens to earlier positions. No forward path means no gradient path. A token that was never read cannot be blamed for the error.
4
(d) True: P(x₁…x_T) = ∏ P(x_t | x₁…x₍t₋₁₎), the chain rule written out, which is the whole content of the CLM objective.
(a), (b), (d) — not (c)
2026 T1 · Q6 and Q7 · 2 marks each

(a) A loop builds AutoModelForMaskedLM.from_pretrained("bert-base-uncased") and calls it with labels=batch_ids on a large domain corpus with no labelled task targets, then backpropagates. What is the most precise interpretation? (b) In the standard Transformer, which component scales quadratically, O(N²), with input sequence length N?

1
(a) Three signals decide it. The class is ForMaskedLM, so the objective is MLM. The corpus is unlabelled and domain-specific. The weights start from a pretrained checkpoint rather than random.
2
Pretrained start + original objective + new domain = continual pre-training. Passing labels=input_ids is not supervision; it is how the MLM collator scores the model on reconstructing its own masked input.
3
So it is not instruction tuning — there are no instructions — and no classifier head is being trained.
4
(b) The attention score matrix QKᵀ is N×N, one entry per pair of positions, so it grows with the square of the length. Embedding lookups are O(N), residual additions are O(N), and the feed-forward layers act position by position, also O(N).
5
Note this is the one place sequence length matters. It drives compute and activation memory — never the parameter count.
(a) continual pre-training with the MLM objective  ·  (b) the attention score matrix QKᵀ
