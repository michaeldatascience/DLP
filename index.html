Two errors found in the course material
  • The week-2 deck's final Viterbi lattice node reads −15.51 for whereby. The correct sum is −8.21 + −7.34 = −15.55, and every intermediate value on the slide matches, so it is a typo in the last node rather than a different method.
  • The deck's WordPiece score table lists only the pairs already shown for BPE, where (a,d) at 0.167 wins. Over every pair in the corpus the real winner is (r,y) at 0.333. Both illustrate the same rule: rare halves beat common halves at equal pair count.
